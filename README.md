# BiblioClasse v0.3 — version rentrée

Cette version est conçue pour être mise en ligne rapidement sur GitHub Pages et synchronisée avec Firebase/Firestore.

Fonctions présentes :

- mode enseignant protégé par PIN ;
- mode élève très simple ;
- ajout ISBN détaillé ;
- inventaire rapide par scan à la chaîne ;
- scan de codes-barres EAN/ISBN compatible mobile via `html5-qrcode` ;
- Google Books + Open Library pour les métadonnées et couvertures ;
- catalogue visuel avec couvertures ;
- recherche rapide par titre, auteur, collection, mot-clé, cote ;
- propriétaires : personnel / classe / école ;
- élèves + archivage ;
- emprunts et retours par scan ;
- profil lecteur simple ;
- livres actifs / en réserve ;
- sélections par période ;
- cotation après inventaire : ML-001, CAB-001, D-001, R-001… ;
- sauvegarde export/import JSON ;
- synchronisation multi-appareils via Firestore.
